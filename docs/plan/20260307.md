### Phase 114 - regenerate 分支剪裁前移到服务层并修正流式占位位置

- 目标：
  - 解决 regenerate 成功前后出现“新 assistant 先落到底部、旧分支未及时剪裁”的回归。
- 实施项：
  - `GrokChatService` 新增服务层持久化 helper，在 regenerate 完成时直接按目标 assistant `responseId` 截断旧分支，再落新 assistant 与 anchors。

  - 两轮后重生成第一轮的后台链路可正确收口到新分支。
  - regenerate 流期间，前端不再同时显示 anchor 后的旧分支。
  - `bun run typecheck`、定向 `bun test`、全量 `bun test` 通过。
