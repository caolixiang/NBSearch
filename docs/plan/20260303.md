# 今日目标

- 支持“对话 A 生成中时，用户可切换到对话 B 浏览/操作，再切回 A 继续看到实时进度”。
- 不中断后台已发起的流式请求，不丢失中间状态。

## 范围

- In:
  - 将单实例流式状态改为会话级状态管理。
  - 明确切换会话时的状态保留与并发规则。
  - 保持现有 repository + 本地 DB 持久化链路不变。
- Out:
  - 本阶段不引入 `react-query`。
  - 不做 e2e 测试体系建设。

## Phase 计划

### Phase 1 - 会话级流式状态改造方案确认

- 目标：
  - 完成可执行方案定义，覆盖状态模型、切换行为、并发约束、验收口径。
- 实施项：
  - 状态管理：引入会话级 Store（建议 `zustand`），按 `conversationId` 维护状态。
  - 会话状态字段：`isStreaming`、`assistantDelta`、`reasoningEvents`、`startedAt`、`abortController`、`lastError`。
  - 会话切换：仅变更 `activeConversationId`，不清理其他会话的流式状态。
  - 并发约束：同会话禁止并发两条流；不同会话允许并行流任务。
  - 数据链路：继续使用 repository + 本地 DB 持久化路径。
- 验收项：
  - A 会话生成中可切到 B，会话列表与消息可正常操作。
  - 切回 A 后继续看到 A 的实时流式进度。
  - A 完成后消息正确入库，刷新后内容一致。
  - B 不受 A 流状态污染（不出现串流、错位展示）。
- 状态：done

### Phase 2 - 会话切换不中断流式（第一批实现）

- 目标：
  - 先解除“生成中无法切换会话”的阻塞，并保证切回原会话时可继续看到实时流式内容。
- 实施项：
  - 将消息缓存改为按 `conversationId` 存储（`messagesByConversationId`）。
  - 将推理事件映射改为按 `conversationId` + `messageId/responseId` 双层存储。
  - 新增会话级流式状态映射 `streamingStateByConversationId`，流式渲染按当前会话读取，避免跨会话串流显示。
  - 切换会话时不再重置流式状态；若目标会话正在流式，保留本地流式视图，不强制 reload 覆盖。
  - 会话删除时清理对应会话缓存映射（消息、推理、错误）。
- 验收项：
  - 流式进行中可切到其他会话并浏览历史消息。
  - 切回原会话可继续看到正在流式输出的内容。
  - 历史会话与当前流式会话不再出现 UI 串流展示。
- 状态：done

### Phase 3 - 会话状态迁移至 Zustand

- 目标：
  - 将 `chat-shell` 中的会话级状态迁移到 `zustand`，降低组件复杂度并统一状态写入口。
- 实施项：
  - 新增 `chat-conversation-store.ts`，承载会话级核心状态与写操作（active/draft/messages/streaming/reasoning/error）。
  - `chat-shell` 切换为使用 store 状态与 action，不再直接持有上述会话级 `useState`。
  - 新增 `chat-conversation-store.test.ts` 覆盖 store 关键读写行为。
- 验收项：
  - 会话切换与并行流式行为与 Phase 2 保持一致。
  - `typecheck/build` 通过，新增 store 单测通过。
- 状态：done

### Phase 4 - Markdown 与底部滚动抖动修复

- 目标：
  - 修复年份区间 `2017-2021` 被错误拆成 markdown 列表的问题。
  - 修复到底部时输入框反复收起/弹出的乒乓抖动问题。
- 实施项：
  - 从本地 SQLite 读取 `嵇鹏飞：抖音电商转型核心操盘手` 原始消息复现渲染链路。
  - 移除 `normalizeAssistantMarkdown` 中“标题内遇 `-` 强制换行”的误伤规则，保留年份区间原样。
  - 新增 markdown 单测覆盖：跨行年份区间、标题年份区间不被拆分。
  - 调整消息区滚动收起策略：引入“底部锁定区 + 进出阈值滞回”，在底部附近保持输入框稳定，离开底部后恢复原有收起交互。
  - 保持消息滚动容器 `overscroll-y-none`，并保留较小的底部 spacer 上限。
- 验收项：
  - `字节跳动内部晋升路径（2017-2021）` 不再渲染为黑点列表。
  - 到达底部后不再出现输入框高频乒乓弹跳，特别是图片会话（如 `画一只老母鸡`）。
  - `bun test`、`bun run typecheck`、`bun run build` 通过。
- 状态：done

### Phase 5 - Markdown 标题层级增强

- 目标：
  - 让 `#` `##` `###` `####` 与正文形成清晰字号层级，提升长文浏览可读性。
- 实施项：
  - 调整 `MarkdownBody` 中 `h1~h4` 的渲染样式，按 `3xl/2xl/xl/lg` 分级并补齐 `h4` 映射。
  - 保持正文段落样式不变，避免破坏现有排版密度与图片混排逻辑。
- 验收项：
  - 标题层级在视觉上明显区分，且与正文字号有清晰差异。
  - `bun run typecheck` 与 markdown 相关单测通过。
- 状态：done

### Phase 6 - 输入框收起交互方向修正

- 目标：
  - 保留“上滑收起输入框”的交互，同时确保“下滑不收起”以减少阅读干扰。
- 实施项：
  - 调整 `handleMessagesScroll` 判定：仅当用户上滑时触发收起与回弹计时。
  - 非可滚动场景、底部锁定区、下滑场景统一保持输入框展开。
  - 保持底部锁定区与滞回阈值策略，避免到底部时抖动回归。
- 验收项：
  - 向下滑动时输入框不收起。
  - 向上滑动时输入框可收起并按既有时序回弹。
  - `bun run typecheck` 与 `bun test` 通过。
- 状态：done

### Phase 7 - Markdown 图片点击预览

- 目标：
  - 支持点击 markdown 图片进入原图预览，并在点击图片外区域后自动关闭。
- 实施项：
  - 在 `MarkdownImage` 增加预览弹层状态，点击图片时打开弹层并拦截默认链接跳转。
  - 使用现有 `Dialog` 组件渲染大图预览，点击遮罩关闭（保留 Esc 关闭）。
  - 保持图片加载失败、重试与下载逻辑不变，仅增强查看交互。
- 验收项：
  - 点击图片可打开原图预览。
  - 点击弹层外区域可自动关闭预览。
  - `bun run typecheck` 与 `bun test` 通过。
- 状态：done
