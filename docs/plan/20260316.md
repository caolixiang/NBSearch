# 今日目标

- 修复侧边栏对话标题编辑按钮缺少明确 hover 反馈的问题。
- 增加会话星标能力，并确保老库升级后原有会话不丢失。

## 范围

- In:
- 优化侧边栏会话行中“重命名对话”按钮的鼠标悬停交互。
- 补充本次任务的计划、测试与提交记录。
- Out:
- 不改动侧边栏布局。
- 不调整删除按钮语义。
- 不做新的交互流程改版。

## Phase 计划

### Phase 1 - 修复标题编辑按钮 hover 反馈

- 目标：让侧边栏标题编辑按钮在鼠标移动上去时有清晰、稳定的视觉反馈。
- 实施项：
- 检查会话行操作按钮的显示与 hover 样式。
- 以最小改动增强编辑按钮 hover/active/focus-visible 反馈。
- 进行必要校验并记录结果。
- 验收项：
- 鼠标移入编辑按钮时有明显 hover 反馈。
- 不影响当前重命名与删除功能。
- `bun test`、`bun run typecheck` 通过。
- 状态：done

### Phase 3 - 会话星标与老库迁移兼容

- 目标：实现会话星标持久化、侧边栏 `星标` 分组置顶，并修复老数据库在新增字段后会话列表被查空的问题。
- 实施项：
- 在会话存储模型、内存仓储和 SQLite 仓储中新增 `starred` 字段与更新接口。
- 为 `conversations` 表增加 `starred` migration，并调整数据库初始化逻辑，让已打开旧连接也会补跑 migration。
- 在侧边栏加入星标按钮、`星标` 分组和适当的宽度调整。
- 补充星标排序、星标保留、老库迁移相关测试。
- 验收项：
- 支持星标与取消星标，取消后回到原本时间排序。
- `星标` 分组显示在 `今天`、`更早` 之前并置顶。
- 旧库升级后原有对话仍可显示。
- `bun test`、`bun run typecheck`、`bun run build` 通过。
- 状态：done

### Phase 2 - 收敛标题编辑按钮 hover 视觉

- 目标：去掉编辑按钮 hover 时突兀的偏白底色，让交互反馈更贴近侧边栏整体色板。
- 实施项：
- 调整编辑按钮 hover 背景与边框颜色，保留清晰的交互反馈。
- 保持 focus-visible 与禁用态不变。
- 进行必要校验并记录结果。
- 验收项：
- 鼠标移入编辑按钮时仍有明确反馈，但不再出现突兀白底。
- 不影响当前重命名与删除功能。
- `bun test`、`bun run typecheck` 通过。
- 状态：done

### Phase 4 - 迁移事务与旧库升级夹具测试

- 目标：为 SQLite migration 增加事务保护，并用真实 v1 夹具验证旧库升级不会丢会话。
- 实施项：
- 将 migration 执行抽离为可测试的 runtime helper。
- 为每个 migration 增加 `BEGIN IMMEDIATE / COMMIT / ROLLBACK` 事务包裹。
- 新增 `legacy-v1.sql` 夹具，验证旧会话升级后仍能查询到且 `starred` 默认值正确。
- 新增失败 migration 回滚测试，验证不会留下半迁移状态。
- 验收项：
- 旧库夹具升级后保留原有会话数据。
- 失败 migration 不会留下部分 schema 变更，也不会误写 `schema_migrations`。
- `bun test`、`bun run typecheck`、`bun run build` 通过。
- 状态：done

## Phase 验收记录

### Phase 1

- 验收结果：已增强侧边栏编辑/删除按钮的 hover、border 与 focus-visible 反馈，激活会话行内也能明显识别悬停状态。
- 备注：仅调整按钮交互样式，未改动会话列表布局与行为逻辑。

### Phase 2

- 验收结果：已将编辑按钮 hover 底色从偏白卡片色收敛为更贴近侧边栏底色的暖色层次，并保留边框、focus 与按压反馈。
- 备注：本轮只收敛编辑按钮 hover 视觉，不扩散到侧边栏其它组件。

### Phase 3

- 验收结果：已完成会话星标持久化、侧边栏 `星标` 分组、侧边栏宽度调整，并修复旧库连接未补跑 migration 时会话查询失败的问题。
- 备注：星标切换不会改写 `updatedAt`，因此取消星标后仍按原本时间排序回退。

### Phase 4

- 验收结果：已为 migration 增加事务保护，并通过真实 v1 夹具测试验证旧会话升级后仍可读；同时新增失败 migration 回滚测试。
- 备注：运行时仍保持“每次取 DB 先做版本检测”，但已应用版本不会重复执行，只会做轻量比对。
