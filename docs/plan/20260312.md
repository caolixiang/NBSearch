## Phase 计划

### Phase 198 - 恢复正文 Inline Citation Pill

- 目标：让 assistant 正文中的 citation tag 渲染为官网类似的域名 pill，同时保留现有底部 `Key Citations` 列表作为汇总入口。
- 实施项：
- 调整 `expandGrokRenderTags`，将 `citation_card` 展开为内联 markdown 链接，并对紧邻重复 URL 做最小去重。
- 调整 `MarkdownBody` 的 `a` 渲染器，仅对“域名文本 = 链接域名”的链接启用 pill 样式，保持图片链接和普通正文链接不变。
- 补充 markdown / citation 回归测试，锁住 inline pill 展开与底部 citations 共存行为。
- 验收项：
- 标题 `AI Memory & Vector DB Comparison` 的 assistant 正文中可出现域名 pill。
- 现有底部 `Key Citations` 仍可正常展示且无重复回归。
- `bun test`、`bun run typecheck` 通过。
- 状态：done

### Phase 199 - 去重底部重复 Citation

- 目标：让底部 `Key Citations` 对同 URL 的 inline citation 只展示一次，避免 `mem0.ai` / `lancedb.com` 这种重复来源在列表中出现两条。
- 实施项：
- 调整 `buildCitationItems`，对 inline citation 按规范化 URL 去重，不再仅按 `cardId + citationId` 去重。
- 补回归测试，锁住“不同 cardId 指向同一 URL 时底部只保留一条”。
- 验收项：
- `AI Memory & Vector DB Comparison` 的底部 `Key Citations` 中重复来源消失。
- `bun test`、`bun run typecheck` 通过。
- 状态：done
