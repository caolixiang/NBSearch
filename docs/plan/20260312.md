## Phase 计划

### Phase 198 - 恢复正文 Inline Citation Pill

- 目标：让 assistant 正文中的 citation tag 渲染为官网类似的域名 pill，同时保留现有底部 `Key Citations` 列表作为汇总入口。
- 实施项：
- 调整 `expandGrokRenderTags`，将 `citation_card` 展开为内联 markdown 链接，并对紧邻重复 URL 做最小去重。
- 调整 `MarkdownBody` 的 `a` 渲染器，仅对“域名文本 = 链接域名”的链接启用 pill 样式，保持图片链接和普通正文链接不变。
- 补充 markdown / citation 回归测试，锁住 inline pill 展开与底部 citations 共存行为。
- 验收项：
- 标题 `AI Memory & Vector DB Comparison` 的 assistant 正文中可出现域名 pill。
- 现有底部 `Key Citations` 仍可正常展示且无重复回归。
- `bun test`、`bun run typecheck` 通过。
- 状态：done

### Phase 199 - 去重底部重复 Citation

- 目标：让底部 `Key Citations` 对同 URL 的 inline citation 只展示一次，避免 `mem0.ai` / `lancedb.com` 这种重复来源在列表中出现两条。
- 实施项：
- 调整 `buildCitationItems`，对 inline citation 按规范化 URL 去重，不再仅按 `cardId + citationId` 去重。
- 补回归测试，锁住“不同 cardId 指向同一 URL 时底部只保留一条”。
- 验收项：
- `AI Memory & Vector DB Comparison` 的底部 `Key Citations` 中重复来源消失。
- `bun test`、`bun run typecheck` 通过。
- 状态：done

### Phase 200 - 语音控制层与 LiveKit 控制器

- 目标：保留现有原生 LiveKit 链路，补齐语音 token / session-event / 静音 / 文本事件消费所需的控制层能力。
- 实施项：
- 扩展 `VoiceService` 契约，明确 `session_id` 为客户端主键，并补 `instructions/isRawInstructions` 等必要字段。
- 扩展 `GatewayVoiceService`，让 `/api/v1/voice/token` 请求体符合新的 personality/custom 互斥规则与 `session_id` 主链约束。
- 重写 `LivekitSessionController` 的职责边界，支持连接、停止、麦克风静音、扬声器静音、发送文本、消费 `TranscriptionReceived/DataReceived/ChatMessage` 事件，并继续上报必要 session-events。
- 验收项：
- 语音 token 请求体可稳定表达 voice / personality / custom / speed / `session_id`。
- LiveKit 控制器具备连接态、静音态和文本事件消费能力，不再只有 `connect/disconnect` 空壳。
- 定向测试通过。
- 状态：done

### Phase 201 - ChatInput 与会话接线

- 目标：让现有输入框中的语音模式真正接入当前会话与 LiveKit 控制器，形成可用的交互主链路。
- 实施项：
- 在 `ChatShell` 中把当前会话 `session_id`、conversation 元信息和 voice service 控制器接入 `ChatInput`。
- 调整 `ChatInput` 语音模式行为：进入/停止语音、textarea transcript 回显、语音模式 Enter 发送 LiveKit 文本、普通文本模式保持原有发送。
- 记录并持久化最小 voice session 元信息，保证已有对话进入语音时优先沿用已有 `session_id`。
- 补 UI 与控制层回归测试。
- 验收项：
- 已有对话进入语音时不新造客户端 `session_id`。
- 麦克风/扬声器按钮分别映射 LiveKit 原生 mute / volume 能力。
- 语音模式 textarea 不再误走普通文本发送。
- `bun test`、`bun run typecheck` 通过。
- 状态：in_progress
