## Phase 计划

### Phase 45 - DeepSearch 研究结构消费与展示

- 目标：
  - 让 DeepSearch 返回的新研究字段在本地可见、可持久化、可渲染。
- 实施项：
  - 扩展域模型与存储：为 assistant message 增加 research 结构并落库。
  - 扩展流式解析：从 NDJSON 中提取 research（含 steps/citation）并合并到最终消息。
  - 渲染正文注脚：在正文下方显示 `Key Citations` 列表，支持点击跳转。
  - 渲染思考细节：在思考结果抽屉顶部新增“深度挖掘细节”区块。
  - 补充解析层单测与回归测试。
- 验收项：
  - DeepSearch 回复正文下方出现注脚列表（可点击）。
  - 思考结果抽屉出现深度挖掘细节卡片（标题+要点）。
  - `bun run typecheck`、`bun test`、`bun run build` 通过。
- 状态：done

### Phase 46 - DeepSearch 思考结果按 steps 顺序分组对齐

- 目标：
  - 修复思考结果抽屉信息归类错位，按 `research.steps` 的真实顺序展示 `header/summary/tool_usage_card`。
- 实施项：
  - 扩展 `ChatDeepSearchResearch`：新增 `steps` 结构并落库。
  - 扩展解析与合并：从 `x_grok.research.steps` / `modelResponse.steps` 提取并去重持久化。
  - 新增按 steps 分组构建逻辑：将步骤顺序映射到工具事件条目，形成有序分组。
  - 抽屉渲染优先使用 steps 分组视图；无 steps 时回退到既有 `details + toolChain + agent` 视图。
  - 补充 parser / service / structured reasoning 单测。
- 验收项：
  - DeepSearch 思考抽屉按步骤顺序展示，不再拆散分组。
  - `bun run typecheck`、`bun test`、`bun run build` 通过。
- 状态：done
