# 今日目标

- 对齐 DeepSearch 新协议：消费并展示 `x_grok.research` 相关字段，在 UI 中补齐正文注脚与思考细节展示。

## 范围

- In:
  - 解析并持久化 DeepSearch 研究结构（citation / inline_citation / steps / thinking time）。
  - 正文下方渲染注脚列表（可点击打开）。
  - 思考结果抽屉展示“深度挖掘细节”卡片。
- Out:
  - 本阶段不改网关请求参数（继续沿用既有 `x_grok.deep_search=true`）。
  - 本阶段不改 e2e 测试体系。
