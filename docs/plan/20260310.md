### Phase 191 - 首轮时区上下文与每轮本地时间注入

- 目标：新建对话首轮通过 `instructions` 注入稳定的时区/地区上下文，并在每一轮实际请求文本尾部追加隐藏的“本轮权威本地时间”，让模型在续聊时仍能按当前轮次的本地时间回答“现在几点”及“最近24小时/48小时”窗口。
- 实施项：
  - 新增 `gateway-turn-context` helper，负责时区到地点映射、首轮 XML instruction 与每轮本地时间后缀生成。
  - 扩展 `buildGatewayTurnRequestPayload`：仅新建对话首轮写入 `instructions`，所有普通对话轮次在请求文本尾部追加隐藏的本地时间上下文。
  - 将运行时个性化时区配置注入 `GrokChatService` 请求构造链路，并补单测锁住首轮/续聊/附件/重生成行为。
- 验收项：
  - 新建对话首轮请求包含 timezone/location XML instruction。
  - 后续轮次不再重复注入首轮 instruction，但会更新时间后缀。
  - 本地回归测试与真实网关探针验证“现在几点”和“最近24小时/48小时”按本轮注入时间生效。
- 状态：done
