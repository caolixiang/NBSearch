# 今日目标

- 为桌面端增加基于 Jina 的 Polymarket 订阅能力，支持本地持久化、启动补抓、10 分钟轮询与历史分页浏览。

## 范围

- In:
  - 新增本地订阅 schema 与 repository 接口
  - 新增 Jina 抓取、Markdown 解析、去重与轮询服务
  - 启动时自动补抓，运行中每 10 分钟轮询
  - 新增设置开关、订阅列表与“加载更多”
  - 补充单元测试与构建验证
- Out:
  - 不接入现有 Grok HTTP 网关
  - 不保证应用彻底退出期间的完整历史补齐
  - 不实现多账号、多来源订阅
  - 不自动把订阅内容注入聊天上下文
