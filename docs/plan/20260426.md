- 实施项：
  - 修复 `ModelSelector` 的本地展示名判断规则

  - 执行 `bun test` 与 `bun run typecheck`

  - `grok-4.20-0309-reasoning` 显示为 `NBSearch Expert`
  - `grok-4.20-expert` 仍显示为 `NBSearch Max`
  - 测试与类型检查通过
- 状态：done

### Phase 2 - Expert/Max 标题补齐

- 目标：在 Expert / Max 模型完成且上游没有返回标题时，使用 OpenAI 兼容网关总结会话标题；OpenAI 网关未配置或调用失败时，回退到用户提问首句前 10 个字。
- 实施项：
  - 新增聊天标题生成 helper，封装模型档位判断、首句十字回退、OpenAI 标题总结与失败兜底
  - 在正常完成持久化前接入缺失标题补齐，保留上游标题和已有标题优先级
  - 补充 helper 与 `GrokChatService` 集成测试
- 验收项：
  - 上游已返回标题时不触发 OpenAI 标题总结，也不覆盖上游标题
  - Expert / Max 无上游标题且 OpenAI 已配置时，标题来自 OpenAI 总结
  - OpenAI 未配置时，标题回退为用户提问首句前 10 个字
  - `bun test` 与 `bun run typecheck` 通过
- 状态：done
