# 今日目标

- 将 `polymarket` / `kalshi` 订阅抓取从 `Jina + timeline parser` 切换为基于网关 `grok fast` 的固定 JSON schema 拉取，并改为基于帖子 `id` 去重、每 30 分钟同步一次。

## 范围

- In:
  - 新增 feed gateway fetch client，使用固定 prompt/schema 拉取 `x.com/Polymarket` 与 `x.com/Kalshi`
  - 调整 feed source config、sync service 与存储去重逻辑，改为基于帖子 `id`
  - 将订阅轮询周期从 10 分钟调整为 30 分钟
  - 更新/替换相关单元测试并完成必要验证
- Out:
  - 不改聊天/语音主链协议
  - 不新增新的 feed UI 字段展示
  - 不在本轮引入新的数据库表
