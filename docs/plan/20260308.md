# 今日目标

- 分阶段重构大文件，先后抽离 `chat-shell.tsx` 共享流式状态机、`grok-chat-service.ts` 恢复协议模块、媒体纯函数模块、媒体工作流模块，再继续切出发送主链的完成态组装器，持续降低回归概率。

## 范围

- In:
  - 为 `chat-shell.tsx` 抽取发送/重生成共享的流式处理辅助模块。
  - 为 `grok-chat-service.ts` 抽取会话恢复协议相关的查询与归一化辅助模块。
  - 为 `grok-chat-service.ts` 抽取媒体续签与 generated image 纯函数模块，并拆分对应纯函数测试。
  - 为 `grok-chat-service.ts` 抽取消息级媒体刷新与流结束卡片收口工作流模块。
  - 为 `grok-chat-service.ts` 抽取流结束后的完成态 turn 组装模块。
  - 保持现有发送、重生成、思考计时、卡片附件、错误处理、恢复协议、媒体续签与图片归并语义不变。
  - 为抽取模块补充或更新单元测试，锁住关键时序、状态归一化与媒体处理回退行为。
  - 执行 `bun run typecheck`、`bun test`、`bun run build` 回归验证。
- Out:
  - 不修改 `GrokChatService` 对外协议与恢复策略。
  - 不调整 UI 样式与交互文案。
  - 不在本 Phase 改动数据库、网络契约或上游接口。
