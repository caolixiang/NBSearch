# 今日目标

- 完成会话链路“所有重试契约”配置化，并增强“仅用户消息未获助手结果”场景的恢复健壮性（自动恢复 + 单按钮重试）。

## 范围

- In:
  - 服务层恢复结果新增 `in_progress` 分支。
  - `turn in_progress` 时基于 `session state` 校验活跃 turn 后执行有限次重试。
  - 超出重试预算时返回明确失败码 `turn_in_progress`。
  - 新增对应单元测试覆盖“可恢复成功”和“超限失败”。
  - 从 `config.toml` 读取 `turn_in_progress` 重试参数并透传到服务层。
  - 扩展为“所有重试契约”配置化：`stream idle`、`not_found` 重发、`in_progress` 轮询与重试、恢复消息 limit。
  - 增加 pending 轮次自动恢复与单按钮重试（仅 `重试`）。
- Out:
  - 不改网关接口与协议字段。
  - 不改前端展示逻辑与文案映射。
